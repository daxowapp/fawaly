# Community conduct

Be considerate, constructive, and specific. Welcome people regardless of background, identity, language, or experience. Critique code and ideas without personal attacks.

Harassment, threats, discrimination, doxxing, credential disclosure, spam, and deceptive claims are not welcome. Respect consent before sharing another person’s project content or model conversations.

Maintainers may edit or remove harmful contributions and restrict participation when needed. Report a concern using GitHub’s reporting tools or a maintainer contact channel already published on their profile; do not publish private evidence in an issue. Maintainers should explain moderation decisions where doing so is safe and respect people’s privacy.

Arabic and English contributions are both welcome. Assume good intent, ask for clarification, and help each other ship useful work.
